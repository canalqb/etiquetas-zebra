CanalQb Zebra Designer (ZPL II)

Guia completo de recursos, atalhos de teclado, pré-visualização ao vivo e geração de etiquetas térmicas Zebra.

1. Teclas de Atalho & Produtividade
Ação Combinação de Teclas Descrição do Recurso
Desfazer Ctrl + Z Desfaz a última alteração realizada no canvas (posição, texto, dimensões).
Refazer Ctrl + Y ou Ctrl + Shift + Z Refaz a última ação desfeita no histórico.
Copiar Ctrl + C Copia todos os elementos atualmente selecionados.
Recortar Ctrl + X Recorta os elementos selecionados.
Colar Ctrl + V Cola os elementos copiados/recortados na posição atual do cursor.
Imprimir Direto Ctrl + P Envia a etiqueta para o IP da impressora Zebra configurada (abre IP se não houver).
Redimensionar Ctrl + Arraste Segurar Ctrl enquanto arrasta o mouse ajusta a largura/altura/fonte do elemento.
Rotacionar Shift + Arraste Gira os elementos selecionados em incrementos de 90° (0°, 90°, 180°, 270°).
Excluir Delete / Backspace Remove os elementos selecionados do canvas.
Desmarcar Tudo Esc Limpa a seleção atual (nenhum elemento fica marcado).

Seleção por Arraste Arraste Retangular Desenha uma caixa de seleção para selecionar múltiplos elementos. Pode iniciar fora da etiqueta.

2. Studio Visual: Canvas, Réguas e Zoom
Réguas Dinâmicas e Ponto Zero (0,0)

O Canvas emula a etiqueta física sobre a mesa de impressão. O ponto (0,0) fica travado rigorosamente no canto superior esquerdo do papel. Áreas cinzas externas indicam valores negativos fora do papel.

Clique no canto das réguas (ou no botão de bordas) para abrir os limites de margem. As réguas e as grades podem ser ocultadas pelos interruptores abaixo do canvas: Régua, Grade do Palco, Grade da Etiqueta e Ajuste Magnético (snap).

Zoom e Unidades

Barra de zoom com + / −, Auto Fit (ajusta à tela) e Reset 100%.

Seletor de unidade: mm, cm, pol (polegadas) ou dots — todas as medidas do inspetor e das réguas seguem a unidade escolhida.

Dica de Alinhamento:

Se a impressão física sair torta na impressora, abra as Margens e ajuste Esquerda/Superior/Inferior/Direita em mm. O sistema injetará o ajuste de hardware ^LH no código ZPL! Use também o botão Limpar Canvas (com confirmação) para recomeçar do zero.

3. Paleta de Elementos & Inspetor
Paleta (clique ou arraste para o canvas)
  • Texto Livre — rótulo qualquer.
  • Subtítulo — texto de apoio no topo.
  • Nome do Produto — texto em destaque.
  • QR Code — código bidimensional.
  • Código de Barras 128.
  • Linha Divisória e Moldura Externa.
  • Importar Imagem / Logo.
Inspetor do Elemento (barra acima do canvas)
  • Conteúdo/texto, posição X/Y, Fonte (dots) e Largura.
  • Rotação individual: Horizontal, Vertical, Invertido 180° e Vertical Invertido (botão girar 90°).
  • Espessura de linha/moldura em dots (±1 por clique).
  • Estilos de moldura: sólida, tracejada, pontilhada, dupla, arredondada, sombra.
  • Estilos de linha: sólida, tracejada, pontilhada, grossa, dupla, gradiente.
  • Multilinha (^FB): largura do bloco, máx. de linhas e alinhamento (esquerda/centro/direita/justificado).
Barra de Seleção & Aba Elementos

Com um ou mais elementos marcados, a barra flutuante oferece Copiar / Recortar / Colar / Excluir, Negrito (simulado por dupla impressão), Itálico (apenas visual) e Sublinhado. A aba Elementos lista tudo que existe na etiqueta com contagem ao vivo — clique para localizar e editar.

4. Tamanho, Orientação, Densidade e Mídia
Tamanho & Orientação

Presets prontos: 40×25, 100×50, 100×100 e 100×150 mm — ou crie um tamanho personalizado. O botão de orientação alterna Horizontal ↔ Vertical (0°/90°/180°/270°).

Impressão de etiquetas verticais: a impressora Zebra imprime sempre no formato horizontal. O editor converte automaticamente — troca ^PW/^LL e rotaciona cada elemento — garantindo que nada seja cortado.

Densidade & Mídia
  • DPI/dpmm (badge no topo): 203 DPI (8 dots/mm), 300 DPI (12) e 600 DPI (24).
  • Tonalidade (intensidade de queima) enviada como ^MD.
  • Ribbon: Sem ribbon (térmica direta, ^MTD) ou Com ribbon (transferência térmica, ^MTT).
  • Qualidade da imagem: Escala de Cinza (dithering) ou Preto e Branco bitonal (alto contraste).
5. Geração em Lote (Sequências Hierárquicas)
Árvore de Níveis

Sequenciador hierárquico com Nível 1 fixo e botão + Subnível para criar níveis aninhados (Rua → Lote → Caixa). Cada nível tem:

  • Campo Incremental — vincula a sequência à Série, QR Code/Barcode, Nome do Produto ou qualquer texto da etiqueta.
  • Prefixo — texto fixo antes do número (ex.: SN-).
  • Início / Fim / Dígitos — intervalo da contagem com preenchimento de zeros (ex.: dígitos 3 ⇒ 001).
  • Inverso — alterna a ordem Normal (1→X) / Inversa (X→1) por nível.
Ações do Lote

A 1ª combinação é atualizada ao vivo no Canvas. Depois use Gerar Lote (todas as etiquetas aparecem na aba Código ZPL), Imprimir Lote direto ou Exportar/Importar .VIP do modelo especial.

Modo otimizado: com 1 nível, ordem normal e campo de texto, o sistema usa serialização nativa ^SN + ^PQ — a própria impressora incrementa a contagem em 1 único bloco.

6. Modelos Salvos, Exportação e Importação

- Modelos no Cache: salve, carregue e exclua modelos completos direto no navegador.
- Formato .VIP (Modelo Completo): salva toda a geometria da etiqueta, DPI, configurações da impressora, elementos visuais e árvore de sequências do lote.
- Formato .BIN / .JSON (Lote ZPL): baixe ou carregue blocos ZPL concatenados para envio direto.
- Aba Código ZPL: visualize o ZPL ao vivo, copie para a área de transferência ou baixe como arquivo .ZPL.
- Salvamento automático: sua sessão é restaurada automaticamente por até 24h se a página fechar ou recarregar.

7. Impressão: Protocolos, IP e Calibração
Protocolos de Envio (modal de IP)
  • HTTP Direct (/pstprnt) — envio direto do navegador para http://IP/pstprnt (porta 80). Requer impressora Zebra física acessível na rede.
  • TCP 9100 (Raw) e FTP (Porta 21) — exigem o servidor local: rode node print-server.js (fica ativo em localhost:3001) e ele repassa o ZPL para o IP informado.
  • Nuvem / Cloud API — informe uma URL http(s):// no campo de IP.
  • O botão Testar verifica a impressora e o servidor local antes de imprimir.
Impressora Virtual & Utilitários
  • Virtual ZPL Printer (neste PC): configure IP 127.0.0.1 + protocolo TCP 9100 com o print-server.js rodando — cada impressão gera uma imagem renderizada em Documentos\Virtual ZPL Printer\Image Cache.
  • Calibrar: envia comando de calibração de mídia para a Zebra.
  • Extensão Chrome (opcional): rota alternativa de envio via postMessage.
  • O IP e o protocolo escolhidos ficam salvos no navegador e exibidos nos badges do topo.
Erros comuns:

ERR_CONNECTION_REFUSED localhost:3001 = servidor local desligado (rode node print-server.js). POST http://127.0.0.1/pstprnt recusado = protocolo HTTP Direct apontando para o próprio PC (use TCP 9100 para a impressora virtual, ou o IP real da Zebra para HTTP Direct).
