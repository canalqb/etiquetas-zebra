Origem dos dados

A função reconhece automaticamente os 2 tipos: planilha pública ("Qualquer pessoa com o link") e planilha privada da sua conta Google logada no navegador — sem precisar expor o link. A aba indicada no link (gid) é lida.

Só é necessário para planilha privada: no Google Cloud Console, ative a Google Sheets API e crie um OAuth Client ID (tipo "Web application"); em "Origens JavaScript autorizadas" cadastre todos os endereços onde o app roda — http://localhost (XAMPP) e a URL do GitHub Pages (ex.: https://seuusuario.github.io). Sem Client ID, apenas planilhas públicas são lidas. O login exige abrir o app via http(s) — não funciona em file://.

O endpoint precisa responder JSON com CORS liberado para a origem desta página.

Serve para APIs que devolvem JSON (Supabase, PostgREST, Firebase REST, API própria). Não aceita string de conexão SQL crua — banco sem API usa a ponte local do print-server.js.

Escolha uma pasta — todos os arquivos .csv, .txt e .xlsx dela são lidos: o cabeçalho vem do 1º arquivo e as linhas de todos são empilhadas. Sem sincronização automática: se os arquivos mudarem, importe de novo.

Usa a ponte local print-server.js (porta 3001) — o navegador não fala ODBC/socket, então o processo Node consulta por você. Instale o módulo do banco na ponte: npm install odbc / mysql2 / pg / mssql. Credenciais ficam só em memória (nunca salvas).

2. Studio Visual: Canvas, Réguas e Zoom
Réguas Dinâmicas e Ponto Zero (0,0)

O Canvas emula a etiqueta física sobre a mesa de impressão. O ponto (0,0) fica travado rigorosamente no canto superior esquerdo do papel. Áreas cinzas externas indicam valores negativos fora do papel.

Clique no canto das réguas (ou no botão de bordas) para abrir os limites de margem. As réguas e as grades podem ser ocultadas pelos interruptores abaixo do canvas: Régua, Grade do Palco, Grade da Etiqueta e Ajuste Magnético (snap).

Zoom e Unidades

Barra de zoom com + / −, Auto Fit (ajusta à tela) e Reset 100%.

Seletor de unidade: mm, cm, pol (polegadas) ou dots — todas as medidas do inspetor e das réguas seguem a unidade escolhida.

Dica de Alinhamento:

Se a impressão física sair torta na impressora, abra as Margens e ajuste Esquerda/Superior/Inferior/Direita em mm. O sistema injetará o ajuste de hardware ^LH no código ZPL! Use também o botão Limpar Canvas (com confirmação) para recomeçar do zero.

3. Paleta de Elementos & Inspetor
Ribbons de Elementos (clique ou arraste para o canvas)
  • Ribbon "Elementos" (1º): Texto Livre, Subtítulo, Nome do Produto, QR Code, Código de Barras 128, Importar Imagem / Logo, Importar Dados e Clonar (Ctrl+D).
  • Ribbon "Elementos Formas" (2º): Linha Divisória, Moldura Externa, Círculo / Elipse, Diagonal, Cantos Arredondados, Linha Reta e Linha Curva.
  • Linha Reta: a linha ocupa a diagonal da caixa — redimensione a caixa para mudar o ângulo (no inspetor, o botão ↗/↘ inverte a direção).
  • Linha Curva: arraste o ponto azul central para cima/baixo para curvar a linha.
  • Anexação de pontas: com o Ajuste Magnético (snap) ligado, ao arrastar uma linha a ponta gruda na ponta de outra (ex.: 6 linhas anexadas formam um hexágono). Desligue o snap para encaixes livres.
  • Sem sobreposição automática: todo elemento novo nasce em espaço livre — sobrepor só arrastando por decisão sua.
Inspetor do Elemento (barra acima do canvas)
  • Conteúdo/texto, posição X/Y, Fonte (dots) e Largura.
  • Rotação individual: Horizontal, Vertical, Invertido 180° e Vertical Invertido (botão girar 90°).
  • Espessura de linha/moldura em dots (campo, botões ±1) — vale para todas as formas, inclusive retas e curvas.
  • Estilos de moldura: sólida, tracejada, pontilhada, dupla, arredondada, sombra.
  • Estilos de linha: sólida, tracejada, pontilhada, grossa, dupla, gradiente.
  • Quebra automática: todo texto quebra sozinho no limite da caixa (ou da margem direita da etiqueta) — no ZPL sai sempre com quebra de bloco. Ajuste fino: largura do bloco, máx. de linhas e alinhamento (esquerda/centro/direita/justificado).
Edição de texto in-loco:

Duplo clique em qualquer texto (inclusive dentro de formas) abre a edição direto no canvas. Enter confirma, Shift + Enter insere quebra de linha manual e Esc cancela.No teclado do celular, Enter insere quebra de linha — basta tocar fora do campo para salvar o que foi digitado. QR Code e Código de Barras abrem um mini modal para editar o dado. A quebra automática vale para todos os textos — não é preciso ativar nada.

Barra de Seleção & Aba Elementos

Com um ou mais elementos marcados, a barra flutuante oferece Copiar / Recortar / Colar / Excluir, Negrito (simulado por dupla impressão), Itálico (apenas visual) e Sublinhado. A aba Elementos lista tudo que existe na etiqueta com contagem ao vivo — clique para localizar e editar.

4. Tamanho, Orientação, Densidade e Mídia
Tamanho & Orientação

Presets prontos: 40×25, 100×50, 100×100 e 100×150 mm — ou crie um tamanho personalizado. O botão de orientação alterna Horizontal ↔ Vertical (0°/90°/180°/270°).

Impressão de etiquetas verticais: a impressora Zebra imprime sempre no formato horizontal. O editor converte automaticamente — troca ^PW/^LL e rotaciona cada elemento — garantindo que nada seja cortado.

Densidade & Mídia
  • DPI/dpmm (badge no topo): 152, 203, 300 ou 600 DPI.
  • Tonalidade (intensidade de queima) enviada como ^MD.
  • Ribbon: Sem ribbon (térmica direta, ^MTD) ou Com ribbon (transferência térmica, ^MTT).
  • Qualidade da imagem: Escala de Cinza (dithering) ou Preto e Branco bitonal (alto contraste).
5. Geração em Lote (Sequências Hierárquicas)
Árvore de Níveis

Sequenciador hierárquico com Nível 1 fixo e botão + Subnível para criar níveis aninhados (Rua Lote Caixa). Cada nível tem:

  • Campo Incremental — vincula a sequência à Série, QR Code/Barcode, Nome do Produto ou qualquer texto da etiqueta.
  • Prefixo — texto fixo antes do número (ex.: SN-).
  • Início / Fim / Dígitos — intervalo da contagem com preenchimento de zeros (ex.: dígitos 3 ⇒ 001).
  • Inverso — alterna a ordem Normal (1 X) / Inversa (X 1) por nível.
Ações do Lote

A 1ª combinação é atualizada ao vivo no Canvas. Depois use Gerar Lote (todas as etiquetas aparecem na aba Código ZPL), Imprimir Lote direto ou Exportar/Importar .VIP do modelo especial.

Modo otimizado: com 1 nível, ordem normal e campo de texto, o sistema usa serialização nativa ^SN + ^PQ — a própria impressora incrementa a contagem em 1 único bloco.

Barra de Status & Etiqueta de Teste

A barra abaixo do canvas aparece apenas em modo lote ou importação (inclusive com 1 única etiqueta) e mostra o total a gerar + o modo ativo ("etiqueta em lote" / "importar dados"). O botão Testar 1 imprime apenas a 1ª etiqueta, 1 cópia — ideal para conferir o layout antes de mandar o lote inteiro. Em modo normal a barra fica oculta.

Importar Dados (uma etiqueta por linha)

Botão Importar Dados (ribbon Elementos): Excel (.xlsx), CSV/TXT, Google Sheets (link público ou privado da sua conta com Client ID), Webhook, Banco/API, Pasta compartilhada e Ponte local ODBC (com o print-server.js rodando). Mapeie cada coluna a um campo, use Aplicar (gera os elementos) e Gerar Todas as Linhas — na impressão sai 1 etiqueta por linha.

6. Modelos Salvos, Exportação e Importação

- Modelos no Cache: salve, carregue e exclua modelos completos direto no navegador.
- Nova etiqueta em branco (botão Nova): limpa tudo — elementos, lote especial, dados importados e ZPL gerado — com confirmação.
- Formato .VIP (Modelo Completo): salva toda a geometria da etiqueta, DPI, configurações da impressora, elementos visuais e árvore de sequências do lote.
- Formato .BIN / .JSON (Lote ZPL): baixe ou carregue blocos ZPL concatenados para envio direto.
- Aba Código ZPL: visualize o ZPL ao vivo, copie para a área de transferência ou baixe como arquivo .ZPL.
- Salvamento automático: sua sessão é restaurada automaticamente por até 24h se a página fechar ou recarregar.

7. Impressão: Protocolos, IP e Calibração
Protocolos de Envio (modal de IP)
  • HTTP Direct (/pstprnt) — envio direto do navegador para http://IP/pstprnt (porta 80). Requer impressora Zebra física acessível na rede.
  • TCP 9100 (Raw) e FTP (Porta 21) — exigem o servidor local: rode node print-server.js (fica ativo em localhost:3001) e ele repassa o ZPL para o IP informado.
  • Nuvem / Cloud API — informe uma URL http(s):// no campo de IP.
  • O botão Testar verifica a impressora e o servidor local antes de imprimir.
Impressora Virtual & Utilitários
  • Virtual ZPL Printer (neste PC): configure IP 127.0.0.1 + protocolo TCP 9100 com o print-server.js rodando — cada impressão gera uma imagem renderizada em Documentos\Virtual ZPL Printer\Image Cache.
  • Calibrar: envia comando de calibração de mídia para a Zebra.
  • Extensão Chrome (opcional): rota alternativa de envio via postMessage.
  • O IP e o protocolo escolhidos ficam salvos no navegador e exibidos nos badges do topo.
Espelhos, Reverso, Imagem ^GF e o Chip de IP
  • Espelho V / H / V+H (ribbon Configuração): espelha a etiqueta inteira — ideal para transferência térmica. O efeito aparece na Pré-visualização de Impressão.
  • Reverso (^LR): inverte as cores da etiqueta (impressão branca sobre fundo preto).
  • Imprimir como Imagem (^GF): rasteriza a etiqueta exatamente como desenhada — à prova de reposicionamento de mídia na impressora.
  • Chip de IP no topo: duplo clique edita o IP na hora; o pontinho ao lado fica verde quando a impressora responde, vermelho quando falha e cinza sem IP.
Erros comuns:

ERR_CONNECTION_REFUSED localhost:3001 = servidor local desligado (rode node print-server.js). POST http://127.0.0.1/pstprnt recusado = protocolo HTTP Direct apontando para o próprio PC (use TCP 9100 para a impressora virtual, ou o IP real da Zebra para HTTP Direct).

8. Uso no Celular (Mobile)
Menu "Ferramentas"
  • No celular os ribbons viram um menu lateral esquerdo: toque no botão azul Ferramentas (ícone de barras, canto superior esquerdo).
  • Cada seção (Elementos, Formas, Impressora, Modelos, Configuração, Exibição) abre/fecha ao toque no nome — igual um acordeão.
  • Fechar: toque no fundo escuro, tecla Esc ou F1. Ao inserir um elemento o menu fecha sozinho.
  • Reordenar seções (arrastar pelo "grip") e fixar favoritos é recurso do desktop.
Gestos de Toque no Canvas
  • Segurar e arrastar um elemento (1 dedo) — move.
  • Alça (quadradinho do canto) — segurar e arrastar redimensiona.
  • Dois dedos sobre o elemento — pinça expande/contrai: texto muda a fonte, QR/formas mudam o tamanho.
  • Toque longo (~meio segundo parado) — abre o Editor de Elemento em modal (mesma ação do botão direito no PC).
  • Toque duplo — edita texto/formas direto no canvas; QR e código de barras abrem um mini modal. No teclado, Enter quebra linha e tocar fora do campo salva.
  • Tocar no fundo (fora dos elementos) — desmarca tudo. Fora do canvas a página rola normalmente.
Editor de Elemento e Zoom no celular

Ao selecionar, o Editor de Elemento aparece embaixo do canvas com os ícones organizados em várias linhas — nada estoura a tela. Pelo toque longo ele abre como modal, com campos grandes e confortáveis (ideal para digitar). Zoom do canvas: botões + / − / Auto Fit no menu Ferramentas → Exibição.

Pressione F1 em qualquer momento para abrir esta ajuda. Toque no botão de interrogação para reabrir esta ajuda a qualquer momento.
