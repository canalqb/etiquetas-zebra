Solicitação de Exclusão de Dados/Conta

Última atualização: 25 de setembro de 2026 · Mantido por CanalQb · Página estática — nenhum dado pessoal é coletado aqui.

Que dados existem para excluir?

Só dois tipos, e ambos estão sob seu controle. Primeiro, os dados locais que o editor guarda no seu navegador (etiquetas em edição, modelos salvos, IP da impressora e preferências — todas as chaves começam com o prefixo etiquetasZebra.). Segundo, os chamados públicos que você pode ter aberto no GitHub ao usar nossa página de contato. Não há contas de usuário, banco de dados ou histórico em servidor algum para excluir.

Como apagar os dados locais agora?

O botão abaixo remove, de forma imediata e irreversível, todos os registros do Etiquetas Zebra guardados neste navegador. As etiquetas em edição e os modelos salvos serão perdidos — se quiser preservar algo, exporte os modelos pelo editor antes de prosseguir. O tema da página também volta ao padrão claro.

Como apagar pelos menus do navegador?

  1. Chrome/Edge: ícone ⋮/… → “Excluir dados de navegação” → marque “Cookies e outros dados de sites” → intervalo “Todo o período”.
  2. Firefox: menu → Configurações → Privacidade e Segurança → “Cookies e dados de sites” → “Gerar dados…” → limpe os dados deste site.
  3. Modo cirúrgico (qualquer navegador): abra as ferramentas de desenvolvedor (F12) → guia Application/Armazenamento → Local Storage → selecione este site e apague as chaves com o prefixo etiquetasZebra..

Como excluir meus chamados do GitHub?

Chamados abertos pela página de contato ficam na sua conta GitHub, sob seu domínio: acesse o repositório, abra a aba Issues, localize o seu chamado e use a opção de fechar/excluir disponível para o autor. Se você não tem conta ou perdeu o acesso, abra um novo chamado pedindo a exclusão do anterior — inclua o link — e o mantenedor ocultará o conteúdo que estiver ao alcance da moderação.

Não há “conta” para excluir — e agora?

Exato: o serviço não tem cadastro, login ou perfis, então não existe “conta” do Etiquetas Zebra. A única identidade envolvida é a sua conta GitHub, gerida por você diretamente nas configurações dela (Settings → Delete account), independente deste projeto. Se você veio até esta página por exigência de um fluxo formal (por exemplo, de um órgão ou empresa), registre o pedido pelo canal de Contato para receber confirmação por escrito do que foi descrito aqui.

Cookies de publicidade de terceiros (Google) são removidos junto com a limpeza de “dados de sites” do navegador — a publicidade volta ao modo não personalizado.
