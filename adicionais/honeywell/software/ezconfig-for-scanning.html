O que é o EZConfig for Scanning e para que serve?

O EZConfig for Scanning é o utilitário oficial de configuração da Honeywell para Windows — sucessor do Visual Xpress e totalmente compatível com ele. Ele permite alterar parâmetros do leitor, atualizar firmware, testar o dispositivo e gerar cloning barcodes para replicar configurações entre scanners. É gratuito e distribuído pelo portal oficial de software da Honeywell.

Na prática, o EZConfig é o "painel de controle" do seu scanner dentro do Windows. Em vez de imprimir dezenas de códigos de barras de programação (como fazemos no catálogo de comandos do 8675i deste mesmo app), você conecta o leitor por USB e muda tudo pela tela: simbologias habilitadas, prefixo e sufixo dos dados, modo de interface, volume do bipe, padronização de dados enviados ao sistema e até a atualização de firmware do equipamento.

Aqui no @CanalQb, validamos na bancada que o fluxo mais comum é: configurar um único scanner da forma exata que a operação precisa, gerar o cloning barcode (um código de barras que carrega toda a configuração) e colar esse código na parede — qualquer unidade nova é configurada em um único bip, sem abrir o EZConfig de novo. Para quem mantém frota de coletores em produção, isso economiza horas de configuração manual.

O EZConfig também substituiu o antigo Visual Xpress: qualquer parâmetro que você configurava no programa legado funciona igual aqui, porque a Honeywell manteve compatibilidade total com os perfis antigos.

Quais scanners Honeywell são compatíveis com o EZConfig?

A lista oficial cobre as gerações 6 e 7 da Honeywell: os industriais 8620i, 8660i, 8670, 8675i, 8680iB e 8690i, a família Xenon (1900 até 1962), Voyager (1200g até 1472g), Granit (1280i até 1991i e o Ultra 210xi), VuQuest 33x0, além de Genesis, Orbit, Solaris e Stratos. A conexão suportada é USB ou RS232.

Qual versão baixar: EZConfig 4.5.68 ou 3.5.13?

Baixe a 4.5.68 se o seu scanner for das gerações 6 ou 7 — é a versão atual, baseada em navegador, datada de julho de 2026, homologada para Microsoft Edge, Google Chrome, Internet Explorer e Firefox. A 3.5.13 é a versão offline, mantida apenas para os equipamentos legados da era HHP.

A diferença prática importa porque muda o comportamento do software na sua máquina:

Como a 4.x roda no navegador, ela herda as regras de segurança do Chrome — e é exatamente aí que nasce o erro de carregamento que trava muita gente. Guarde essa informação: versão 4.x no Chrome exige o atalho especial. Sem ele, o software abre quebrado. Já a 3.5.13 abre como qualquer programa Windows, sem depender de navegador.

Por que o antivírus acusa vírus no instalador do EZConfig?

É um falso positivo. O EZConfig não é assinado com certificado digital da Microsoft, então o Windows SmartScreen e antivírus heurísticos marcam o instalador como "aplicativo não reconhecido". O arquivo é o mesmo distribuído pelo portal oficial da Honeywell — o alerta aponta a ausência de certificação, não a presença de malware.

Entenda o raciocínio do antivírus: ele não lê só o código, ele pontua a "reputação" do arquivo. Software de grande fabricante mas sem certificado de assinatura digital, baixado por pouca gente no mundo, com instalador que descompacta HTML e executa scripts — para um antivírus heurístico, esse perfil se parece com o de um adware, mesmo sendo legítimo. A Honeywell inclusive mantém um artigo oficial de suporte sobre exatamente esse problema, o "EZConfig for Scanning Downloaded from Honeywell Website Failing Virus Scan" — ou seja: reclamação de vírus no arquivo oficial é ocorrência documentada, não novidade.

Como proceder com segurança: baixe apenas pelo portal oficial da Honeywell ou pelo encurtado https://canalqb.com.br/?c=ezconfig4_5_68 (que aponta para o arquivo do portal). No alerta do SmartScreen, clique em "Mais informações" e "Executar assim mesmo". Se quiser paranoia saudável (aprovamos), envie o arquivo para o VirusTotal antes de executar — você verá no máximo detecções genéricas de "PUA/heurística", nunca uma praga identificada com nome próprio. O que você NUNCA deve fazer é baixar EZConfig de sites de "download grátis" genéricos.

Por que o EZConfig não carrega no Chrome?

Porque a versão 4.x é uma aplicação HTML que roda localmente e precisa ler os próprios arquivos de configuração pelo protocolo file. O Chrome bloqueia esse acesso por padrão — daí o EZConfig mostrar os erros abaixo em vez de abrir. A correção é abrir o navegador com a flag --allow-file-access-from-files, exatamente como o instalador faz quando cria o atalho da área de trabalho.

Estas são as mensagens reais que aparecem quando isso acontece:

Erro 1 — o EZConfig não consegue carregar a configuração:
Unable to load the configuration file, Application may not work as desired

Erro 2 — o Chrome não liberou o acesso aos arquivos locais:
Please close running instances of Chrome and re-launch Chrome with '--allow-file-access-from-files' parameter, or re-install EZConfig to have the installer create a shortcut on your desktop

Erro 3 — a configuração corrompeu após tentativas de abrir direto:
EZCS configuration has been corrupted, request you to uninstall and install it again

A mensagem do Erro 2 é literal: o próprio EZConfig está pedindo para fechar TODAS as instâncias do Chrome e reabrir com o parâmetro --allow-file-access-from-files, ou reinstalar o EZConfig para o instalador criar o atalho correto na área de trabalho. O Erro 3 é o desdobramento: depois de abrir o HTML direto pelo Chrome comum várias vezes, os arquivos de configuração locais corrompem e nem o atalho certo resolve — entra a instalação limpa.

Por que não criar a flag na mão no seu Chrome principal? Porque --allow-file-access-from-files desliga uma proteção de segurança do navegador para TODOS os sites locais que você abrir nessa sessão, não só para o EZConfig. A recomendação da Honeywell (e nossa) é deixar que o próprio instalador crie o atalho — ele nasce com a flag e aponta só para o EZConfig. A criação manual que ensino mais abaixo é plano B, para quem já tem a instalação e não quer reinstalar.

Como carregar o EZConfig corretamente no navegador?

A forma correta é instalar o EZConfig e abrir pelo atalho que o próprio instalador cria na área de trabalho — ele já inicia o navegador com a flag necessária. Se a configuração já corrompeu, faça a instalação limpa: feche todo o Chrome, desinstale o EZConfig, reinicie o PC, baixe de novo e instale como administrador.

Seguimos aqui o Protocolo de Profundidade: cada passo com o clique exato, o porquê e o resultado esperado.

Passo 1: Feche o Chrome por completo

Fechar a janela não basta — o Chrome continua rodando em segundo plano. Pressione Ctrl + Shift + Esc para abrir o Gerenciador de Tarefas, procure por processos "Google Chrome" ou chrome.exe na aba Processos e clique em "Finalizar tarefa" em cada um. Só com o Chrome 100% morto o instalador consegue recriar o atalho e o navegador reabre com a flag valendo.

Erro comum: pular este passo. Aí o instalador avisa que "há instâncias do Chrome em execução", a instalação segue pela metade e o atalho novo nem nasce.

Passo 2: Desinstale o EZConfig pelo Windows

Abra Configurações (tecla Windows + I), Apps, Aplicativos instalados, localize "EZConfig for Scanning" e desinstale. Isso remove os arquivos de configuração corrompidos (o tal "EZCS configuration has been corrupted") — sem isso, reinstalar por cima mantém a corrupção.

Erro comum: reinstalar sem desinstalar. O instalador não substitui a configuração corrompida, então os erros voltam exatamente iguais — e você perde tempo achando que a versão nova veio quebrada.

Passo 3: Reinicie o computador

Reinicie (não é "desligar e ligar rápido", use Reiniciar). Isso libera arquivos que o Windows mantinha travados do processo antigo e limpa sessões do Chrome que ficam presas na inicialização.

Passo 4: Baixe o instalador de novo

Baixe a 4.5.68 pelo encurtador https://canalqb.com.br/?c=ezconfig4_5_68 ou direto pelo portal oficial no caminho Current. Baixe de novo do zero — não reaproveite o ZIP antigo de pasta de Downloads, porque a corrupção pode estar nele.

Passo 5: Instale como administrador

Clique com o botão direito no instalador e escolha "Executar como administrador". Instalar como administrador garante que o instalador consiga gravar na área de trabalho, registrar os arquivos locais e criar o atalho com a flag do Chrome — a instalação comum, em conta sem privilégio, às vezes silencia justamente essa etapa. Resultado esperado: ao final, um ícone novo do EZConfig aparece na sua área de trabalho.

Passo 6: Abra SEMPRE pelo atalho da área de trabalho

Dê um clique duplo no atalho criado pelo instalador — não no HTML que está na pasta do EZConfig, não no Chrome do dia a dia. O atalho embute a flag --allow-file-access-from-files e abre o navegador já com a permissão certa. Se a tela do EZConfig carregar com os menus de configuração e o scanner aparecendo na lista de dispositivos, funcionou.

Passo 7: Conecte o scanner e valide

Com o EZConfig aberto, conecte o 8675i (ou seu modelo) por USB e confira se ele aparece na área de dispositivo conectado. Se aparecer, o software está enxergando o leitor. Se não aparecer, pule direto para a seção sobre detecção de scanner mais abaixo — o problema lá é outro parâmetro (REMIFC), não o Chrome.

Checklist da instalação correta: Chrome totalmente fechado antes de instalar, desinstalação prévia se já houve erro, execução como administrador e abertura sempre pelo atalho do instalador. Cumprindo os quatro, os três erros da tela preta acima desaparecem.

Como criar um atalho manual do Chrome para o EZConfig?

Crie um atalho cujo destino aponte para o chrome.exe seguido de --allow-file-access-from-files e abra o EZConfig sempre por ele. Funciona como o atalho do instalador, mas exige dois cuidados: o caminho entre aspas quando tiver espaços e o entendimento de que a flag vale para toda a sessão do navegador aberta por ele.

Este é o plano B para quem já tem o EZConfig instalado e funcionando em outra máquina, ou quem perdeu o atalho. Cada passo com o clique exato:

Passo 1: Localize o chrome.exe na sua máquina

No Windows de 64 bits, o Chrome costuma estar em C:\Program Files\Google\Chrome\Application\chrome.exe. Em instalações antigas de 32 bits, fica em C:\Program Files (x86)\Google\Chrome\Application\chrome.exe. Confirme no Explorador de Arquivos antes de prosseguir — se o caminho estiver errado, o atalho simplesmente não abre nada.

C:\Program Files\Google\Chrome\Application\chrome.exe
:: ou, em instalação 32 bits:
C:\Program Files (x86)\Google\Chrome\Application\chrome.exe

Passo 2: Crie o atalho na área de trabalho

Clique com o botão direito numa área vazia da área de trabalho, vá em Novo e depois Atalho. O Windows pergunta o local do item: cole o caminho completo do chrome.exe (com aspas, porque "Program Files" tem espaço). Nomeie como "EZConfig — Chrome" para não confundir com o atalho do Chrome comum.

Passo 3: Edite o destino e acrescente a flag

Botão direito no atalho recém-criado, Propriedades, campo "Destino". Ele está assim:

"C:\Program Files\Google\Chrome\Application\chrome.exe"

Deixe exatamente assim — o chrome.exe entre aspas e a flag DEPOIS, fora das aspas:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --allow-file-access-from-files

Clique em OK para salvar. Se o Windows recusar com "o nome informado não é válido", sobrou um caractere fora do lugar — apague tudo e cole de novo a linha inteira do bloco acima.

Erro comum: colar a flag para DENTRO das aspas. Aí o Windows procura por um arquivo chamado "chrome.exe --allow-file-access-from-files", que não existe, e o atalho falha com "destino inválido". As aspas fecham no .exe; a flag vem depois, separada por espaço.

Passo 4: Abra o EZConfig por este atalho

Dê clique duplo no atalho "EZConfig — Chrome". Ele abre uma janela do Chrome com a proteção de arquivos locais liberada. Nesta janela, abra a página do EZConfig (o HTML da pasta onde ele está instalado) — o software carrega com os menus completos, sem o erro "Unable to load the configuration file".

Passo 5: Use este atalho só para o EZConfig

A flag vale para a sessão inteira dessa janela — não use esse atalho para navegar em sites da internet. A biblioteca do Chrome aberta por ele considera que qualquer página local pode ler arquivos locais, o que não é o padrão seguro para navegação comum. O atalho do instalador da Honeywell tem o mesmo efeito, por isso a recomendação oficial é preferir reinstalar e usar o atalho que ele cria — o resultado é o mesmo, mas quem cuida da configuração é o próprio EZConfig, reduzindo a chance de erro manual.

E se o scanner não for detectado pelo EZConfig?

Se o scanner está no modo padrão de USB keyboard emulation (TRMUSB124, PAP124) com o REMIFC desativado, a descoberta do dispositivo pode falhar. A Honeywell recomenda habilitar REMIFC1 para melhorar a detecção. Já para comunicação por porta serial virtual (TRMUSB130), é preciso instalar o HSM USB Serial Driver.

Dois ajustes resolvem 90% dos casos de "apareceu tudo, menos o scanner":

  • REMIFC em 1: o REMIFC (Remote MasterMind) desligado (valor 0, padrão de fábrica) atrapalha o EZConfig 4.x a enxergar o leitor em emulação de teclado. Habilite REMIFC1 pela interface do EZConfig em Device Settings, ou pelos códigos de programação do guia do usuário do seu modelo. No 8675i, o comando de menu segue o mesmo formato de comandos SYN que você encontra no catálogo de comandos do 8675i que publicamos aqui no app.
  • Driver serial quando usar TRMUSB130: se você trocou a interface do leitor para USB Serial Emulation (TRMUSB130), o EZConfig só conversa por uma porta COM virtual — e essa porta exige o HSM USB Serial Driver (artigo 000022739 da Honeywell). O Windows 10 já traz um driver serial genérico, mas ele não suporta tudo: funcionalidades como captura de imagem do leitor e comandos como REVINF precisam do driver oficial da Honeywell.

Feito isso, desconecte e reconecte o USB e abra o EZConfig de novo pelo atalho correto. O scanner deve aparecer na lista de dispositivos conectados em poucos segundos.

Perguntas Frequentes

O EZConfig for Scanning é gratuito?

Sim. O EZConfig é um utilitário de suporte distribuído gratuitamente pela Honeywell no portal oficial de software — não exige licença paga nem assinatura para baixar e instalar. Qualquer site cobrando pelo download não é a fonte oficial. Você encontra o arquivo pelo encurtado https://canalqb.com.br/?c=ezconfig4_5_68 ou navegando pelo portal da Honeywell.

O EZConfig funciona no Windows 11?

Funciona. A versão 4.x roda dentro do navegador — Edge, Chrome, Internet Explorer e Firefox são os homologados — então o que manda é o navegador estar com a permissão de acesso a arquivos locais (o atalho do instalador cuida disso), não a versão do Windows. Para os recursos de porta serial (TRMUSB130), o HSM USB Serial Driver é o mesmo do Windows 10. Se quiser garantir comportamento estável, siga a instalação limpa deste guia.

Preciso de conta Honeywell para baixar o EZConfig?

Não. O portal de download é aberto: você entra em hsmftp.honeywell.com, navega até Tools and Utilities e baixa o EZConfig sem login. A conta só é útil para abrir chamados de suporte no SPS Community, como o artigo oficial 000055083 que documenta o download.

O que é um cloning barcode e por que gerar um?

É um código de barras que carrega dentro de si a configuração completa do scanner que o gerou. Ao bipar esse código em outro leitor compatível, ele assume a mesma configuração — ideal para padronizar uma frota inteira sem configurar unidade por unidade. No EZConfig, você configura um leitor do jeito certo e gera o cloning barcode para replicar nos demais; é mais rápido e menos propenso a erro humano do que repetir cada ajuste manualmente.

Como resolvo o erro "EZCS configuration has been corrupted"?

Esse erro indica que os arquivos locais de configuração do EZConfig corromperam — geralmente depois de abrir o HTML direto pelo Chrome sem a flag. A solução é a instalação limpa: feche todo o Chrome pelo Gerenciador de Tarefas, desinstale o EZConfig em Configurações, reinicie o PC, baixe a 4.5.68 de novo e instale como administrador. Depois, abra sempre pelo atalho criado pelo instalador — a seção "Como carregar o EZConfig corretamente no navegador" deste guia traz o passo a passo completo.

O EZConfig substitui o Visual Xpress?

Sim. O EZConfig for Scanning é o sucessor oficial do Visual Xpress e mantém compatibilidade total com os perfis criados no programa antigo — você pode carregar uma configuração gerada no Visual Xpress no EZConfig sem conversão. A Honeywell recomenda a migração completa, mantendo o Visual Xpress apenas para equipamentos muito antigos já fora da lista de suporte.
